# AI Career Mentor 🚀

AI Career Mentor is an AI-powered career guidance platform designed to help students and aspiring professionals navigate their learning journey.

The application analyzes a user's career goal and provides:

✅ Recommended skills

✅ Learning roadmap

✅ Project suggestions

✅ Career guidance

The goal of this project is to make career planning easier and more personalized for students entering the fields of Artificial Intelligence, Data Science, and Software Development.

## Technologies Used

- Python
- Google Colab
- GitHub

## Current Features (V1)

- Career goal selection
- Skill recommendations
- Project suggestions
- Basic career guidance
